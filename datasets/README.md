# Dataset directory

Datasets used for the experiments live under `../datasets/`.

Dataset to be run is chosen in `configs/config.json` under the property `CHOSEN_DATASET` and the options are :"so/german/acs".

repo:

- **german:** `datasets/german_not_encoded.csv`
- **so:** `datasets/stackoverflow_not_encoded.csv`
- **acs:** `datasets/acs_encoded.csv`

Rules files (e.g. `GermanChosen10Treatments.json`, `Chosen10Treatments.json`) live in `configs/` and are already in the repo.
